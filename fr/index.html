L'histoire

Né d'un vrai problème de DJ

Je suis Hervé, le fondateur de TrackZapDJ. J'ai commencé à mixer en club à la fin des années 80, sur vinyle et sur nos chères MK2 : la New Wave, puis la House, la New Beat et l'Electro. Je n'ai jamais vraiment lâché les platines, même quand ma vie professionnelle a pris le dessus : je suis resté un amateur éclairé.

Pendant le Covid, j'ai franchi le pas du contrôleur — une DDJ-1000 avec Rekordbox. Les gigaoctets de MP3 se sont accumulés, venus de sources différentes, et ma collection numérique s'est remplie de doublons.

Il existe des suites logicielles complètes, riches en fonctionnalités, qui gèrent aussi les doublons. Mais pour mon usage, elles étaient trop chères et ne répondaient pas précisément à ce besoin. J'ai donc créé TrackZapDJ, un projet indépendant : la version gratuite doit être utile telle quelle, et les achats financent l'hébergement, la maintenance et les nouvelles fonctionnalités.

Questions fréquentes

Vous vous demandez…

TrackZapDJ va-t-il supprimer mes remixes ou mes versions longues ?

Non, pas sans votre accord. L'analyse principale compare l'artiste et le titre : un « Extended Mix » ou un « Radio Edit » dont le titre diffère n'est pas regroupé avec l'original. L'analyse musicale (tonalité, BPM, durée) peut rapprocher des versions proches : le niveau de confiance vous le signale, et rien n'est supprimé sans que vous ayez validé le groupe.

Quelle différence entre la version gratuite et la version payante ?

La version gratuite repère les doublons, propose le morceau à garder, simule le nettoyage et exporte toute l'analyse dans un fichier Excel, sans rien modifier. La version payante appliquera le nettoyage : un seul exemplaire gardé, données rattachées au morceau conservé, sauvegarde et retour en arrière.

Combien coûtera la version payante ? Y a-t-il un abonnement ?

Pas d'abonnement : ce sera un achat unique. Le prix envisagé pour la première version payante est de 3,99 €. Dans une phase ultérieure, il pourra passer à 5,99 € pour les nouveaux acheteurs.

Quand TrackZapDJ sera-t-il disponible ?

La version gratuite sortira en premier : son lancement est prévu début novembre. La version payante viendra dans un second temps ; elle n'est pas encore disponible à l'achat. Écrivez-nous pour recevoir un message à sa sortie.

Que deviennent mes cues, playlists, historiques et tags ?

Lors du nettoyage, vos playlists, vos historiques, votre liste Automix et vos tags passent sur le morceau conservé : vous pouvez toujours rejouer un set passé. Si le morceau conservé est déjà dans une playlist, l'entrée en double est simplement retirée. Vos hot cues et memory cues sont recopiés sur le morceau conservé quand les deux fichiers ont la même durée (à une seconde près), sans doublonner ceux qui existent déjà.

Les doublons sont-ils aussi supprimés de mon disque dur ?

Oui, en version payante, mais pas tout de suite. Les fichiers retirés quittent votre dossier de musique et sont rangés dans le dossier de sauvegarde de votre choix, pour permettre un retour en arrière. Ils sont supprimés définitivement quand le nettoyage sort de l'historique des 5 derniers ; TrackZapDJ vous prévient avant.

Trouve-t-il les fichiers en double qui ne sont pas dans Rekordbox ?

Non. TrackZapDJ travaille sur les morceaux de votre collection Rekordbox et sur les fichiers qui leur correspondent. Un fichier présent sur le disque mais jamais importé dans Rekordbox n'est pas analysé.

La version gratuite modifie-t-elle ma bibliothèque ?

Non. Elle lit votre bibliothèque pour l'analyser et vous montre ce qui pourrait être fait. Aucune base, aucun fichier n'est modifié.

Est-ce que je risque de perdre des données ?

TrackZapDJ est conçu pour limiter ce risque : simulation, validation manuelle, sauvegarde automatique, fichiers mis de côté plutôt qu'effacés et retour en arrière. Aucun outil ne peut toutefois garantir un risque nul : gardez aussi votre propre sauvegarde avant un gros nettoyage.

Ma bibliothèque est-elle envoyée sur Internet ?

Non. Toute l'analyse se fait sur votre ordinateur. Vos morceaux et votre base restent chez vous.

TrackZapDJ fonctionne-t-il sur Mac ?

Pas encore. La première version est disponible uniquement sur PC. L'application est prévue pour fonctionner sur PC et Mac : la version Mac viendra ensuite.

L'application est-elle disponible en anglais ?

Pas encore : elle est en français pour l'instant, mais sera disponible en anglais lors du lancement officiel.
